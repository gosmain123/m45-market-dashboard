Methodology & selection logic
The default Today tab shows only names with a material move. The three sleeve tabs contain the full always-on watchlist without making the page vertically long.

A material flag is triggered by |1D| ≥ 1.5%, |1D vs benchmark| ≥ 1.0%, or |1W| ≥ 4.0%. Forward P/E is the default valuation where forecast EPS is meaningful; banks use P/B, REITs use P/B* as a screening proxy, and loss-making companies can fall back to EV/Sales. The valuation cell is the single detail trigger.

Selection logic
Broad Mover Score = 65% × |1D| + 25% × |sector-relative 1D| + 10% × capped |1W|. A name enters only if |1D| ≥ 3.0% or |sector-relative 1D| ≥ 2.0%.

Signal methodology
50% multi-horizon risk-adjusted trend (1M/3M/6M = 50/30/20), 25% relative strength versus a relevant benchmark, and 25% cross-asset regime alignment. Score ≥ +25 = Overweight; ≤ −25 = Underweight; otherwise Neutral.

Asset lens: equity ETFs show portfolio P/E / earnings yield / dividend yield where available; fixed-income ETFs show issuer YTM / duration / SEC yield / OAS; real-asset ETFs are not given an earnings multiple.
